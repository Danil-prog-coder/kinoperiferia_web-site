# Кинопериферия

Сайт мастерской «Кинопериферия» — аксессуары для кинопроизводства — на Go.
Функциональность перенесена с рабочего сайта, оформление — по новому макету
(тёмная «газетная» вёрстка, Source Serif 4, одна технологическая жёлтая краска).

Весь HTML собирается на сервере, внешних зависимостей нет — только стандартная
библиотека Go. Шаблоны и статика вшиты в бинарник через `go:embed`, поэтому для
запуска достаточно одного файла.

## Запуск

```bash
go run .                       # http://localhost:8080
go test ./...                  # тесты
go build -o kinoperiferia .    # сборка одного бинарника
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `8080` | порт HTTP-сервера |
| `BASE_URL` | пусто | публичный адрес сайта для canonical, Open Graph и `sitemap.xml` |
| `ORDERS_FILE` | `data/orders.jsonl` | файл заявок в формате JSON Lines; пустое значение отключает запись |
| `TELEGRAM_BOT_TOKEN` | пусто | токен бота для уведомлений о заявках |
| `TELEGRAM_CHAT_ID` | пусто | чат, куда бот шлёт заявки |

Уведомления в Telegram включаются, только когда заданы обе переменные бота.
Без них заявки просто пишутся в файл и в лог.

## Маршруты

| Маршрут | Что делает |
|---|---|
| `GET /` | главная: первый экран, каталог с фильтрами, «на заказ», производство, доставка, контакты |
| `GET /catalog` | отдельная страница каталога; `?cat=` — категория, `?sort=` — сортировка |
| `GET /product/{slug}` | страница изделия: цена, характеристики, похожие позиции, разметка Schema.org |
| `GET /order` | форма заявки; `?product=` подставляет изделие |
| `POST /order` | приём заявки: проверка полей, запись в файл, уведомление в Telegram |
| `GET /api/products` | JSON-каталог; поддерживает `cat` и `sort` |
| `GET /api/products/{slug}` | JSON одного изделия (его использует быстрый просмотр) |
| `GET /sitemap.xml`, `GET /robots.txt` | для поисковых систем |
| `GET /healthz` | проверка живости и размер каталога |

Значения `cat` и `sort`: категории — `camera`, `bags`, `light`, `set` (или `all`);
сортировки — `default`, `price-asc`, `price-desc`, `name`. Неизвестные значения
молча сводятся к значениям по умолчанию.

## Как это устроено

```
main.go                 запуск, конфигурация из окружения, корректная остановка
internal/catalog        каталог изделий, фильтрация, сортировка, форматирование цен
internal/site           контакты и текстовые блоки страниц
internal/orders         проверка, хранение и отправка заявок
internal/server         маршруты, шаблоны, JSON API, ограничение частоты заявок
web/templates           шаблоны html/template
web/static              стили, скрипт, favicon
```

Сайт работает без JavaScript: фильтры каталога — обычные ссылки, сортировка —
форма с кнопкой, карточка изделия — отдельная страница. Скрипт добавляет поверх
этого фильтрацию без перезагрузки, быстрый просмотр изделия в оверлее, параллакс
первого экрана и появление блоков при прокрутке.

## Правка контента

* изделия, цены и характеристики — `internal/catalog/catalog.go`;
* контакты и тексты блоков — `internal/site/site.go`;
* оформление — `web/static/css/style.css` (токены цвета и отступов собраны в `:root`).
